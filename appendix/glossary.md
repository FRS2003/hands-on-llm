# 名词小词典 Glossary

> 按主题分组，随时回查。标 ★ 的是需要优先掌握的核心高频词。

## 一、模型结构
- **token**：模型处理文本的最小单位（词/子词/字）。
- **参数量**：模型中可学习数字的个数，如 63.91M 即 6391 万个。
- **自注意力 Self-Attention★**：每个位置用 Q/K/V 与全序列加权聚合信息；softmax(QKᵀ/√d)V。
- **MHA / MQA / GQA★**：多头注意力；MQA 所有 Q 头共享一组 K/V；GQA 让 K/V 头分组共享，是效果与显存的折中（本仓库 8 Q 头、4 KV 头）。
- **位置编码 / RoPE★**：给 token 注入顺序信息；RoPE 通过旋转 Q/K 编码相对位置，外推性好。
- **RMSNorm**：LayerNorm 的简化，只做缩放不减均值，更省更快。
- **SwiGLU**：门控激活函数，比 ReLU/GeLU 效果更好的 FFN 结构。
- **MoE**：混合专家，每次只激活部分专家网络，用稀疏计算扩参数量而不线性增算力。
- **KV Cache★**：推理缓存历史 K/V 避免重复计算；GQA/量化都在压缩它。

## 二、训练流程
- **预训练 Pretrain★**：海量纯文本做 next-token 预测，学语言与知识。
- **SFT 监督微调★**：用(指令,回答)配对教模型遵循指令与对话格式。
- **chat template**：规定 system/user/assistant 角色如何拼成模型输入的固定模板。
- **对齐 Alignment**：让输出符合人类偏好，代表方法 RLHF/PPO、DPO、GRPO。
- **LoRA★**：冻结主干，只训旁路低秩矩阵 A、B（W'=W+BA），属参数高效微调 PEFT。
- **秩 rank**：LoRA 小矩阵的"宽度"，代表可学习增量的信息维度，越小越省。
- **DPO★**：直接用(好答案,坏答案)对、免奖励模型的偏好优化；初始 loss=-ln2≈0.693。
- **GRPO★**：对同一问题采样 G 条、用组内归一化优势更新，免 PPO 的价值网络。
- **policy / reference / reward model**：在学的策略模型 / 冻结当锚的参考模型 / 打分模型。
- **rollout**：用策略模型实际采样生成回答的过程，GRPO 慢就慢在这里。
- **KL 散度**：衡量两个分布差距，训练中惩罚新模型偏离参考模型太远。
- **PPO / PPO-clip**：经典强化学习策略梯度算法，用裁剪限制单步更新幅度。
- **灾难性遗忘★**：学新内容时冲垮旧能力；靠小学习率、冻结主干、KL 约束缓解。
- **消融实验 ablation**：只改一个变量、其余不变来证明某模块作用的对照方法。

## 三、优化与工程
- **epoch / batch / step**：遍历全量一遍 / 一次喂入条数 / 更新一次参数。
- **梯度累积★**：分多次小 batch 算梯度再统一更新，等效大 batch，省显存。
- **学习率 lr / warmup / cosine★**：更新步长；先热身再按余弦平滑衰减。
- **优化器 AdamW**：带自适应学习率与权重衰减的主流优化器。
- **梯度裁剪 grad clip**：限制更新步长上限，防训练爆炸。
- **fp16 / bf16★**：16 位半精度，省显存提速度；bf16 动态范围大、更稳，优先用。
- **混合精度**：部分用半精度算、关键处保 fp32，兼顾速度与稳定。
- **DDP / TP / PP**：数据并行（各卡复制模型分数据）/ 张量并行（层内矩阵切分）/ 管道并行（按层分段）。
- **ZeRO**：DeepSpeed 的优化器状态/梯度/参数分片，分 1/2/3 阶段。
- **梯度检查点 checkpointing**：用重算换显存，丢弃部分中间激活、反向时再算。
- **困惑度 PPL★**：=exp(loss)，越小代表模型越"不困惑"。
- **checkpoint/.pth**：模型权重存档文件。
- **量化 GPTQ/AWQ**：把权重量到 4bit 等低精度以省显存，有轻微精度损失。
- **vLLM / PagedAttention**：高吞吐推理引擎与它的显存分页管理。

## 四、Agent 与 RAG
- **Agent / ReAct★**：以"思考 Reason→行动 Act→观察 Obs"循环调用工具解决任务。
- **Tool / Skill**：原子工具函数 / 由多个工具编排成的高层能力。
- **上下文窗口 / 上下文压缩**：模型一次能看的 token 上限；超限用摘要/外置/占位压缩。
- **多智能体**：Supervisor 规划审批 + Worker 执行的分工协作。
- **RAG★**：检索增强生成，先从知识库检索相关片段再让模型据此回答。
- **BM25 / 稠密检索**：基于词频的稀疏检索 / 基于向量语义的稠密检索。
- **混合检索 / 融合策略**：多路召回后合并排序，两种主流做法——RRF（Reciprocal Rank Fusion，按名次 1/(k+rank) 融合）与分数归一化加权融合；本仓库 05 采用后者（0.6 向量 + 0.4 BM25）。
- **Rerank 重排**：对初召回结果用更强模型精排，提 Top-K 准确率。
- **HyDE**：先让模型生成假设答案，再用它去检索，缓解问题-文档表述鸿沟。
- **chunk / embedding / 向量库**：文本切块 / 文本向量 / 存向量并做近邻检索的库（如 FAISS）。
- **带引文生成**：回答中标注来源文献，便于核查。
