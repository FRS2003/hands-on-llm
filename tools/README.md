# tools · 辅助工具

## md2docx.py —— 把中文 Markdown 教程批量转成 Word

一个零配置的单文件转换器，本仓库所有「小白教程」的 Word 版都由它生成。

### 它做了什么

- 标题层级（`#`~`######`）、GFM 表格（带蓝色表头底纹与边框）、代码围栏（灰底等宽字体）；
- 有序/无序列表（支持缩进层级）、引用块、分隔线；
- 行内 `**粗体**`、`` `代码` ``、`[文字](链接)`，并支持**粗体里再嵌套链接/代码**；
- 中文字体排版：正文宋体 + 英文 Times New Roman、标题微软雅黑深蓝、代码 Consolas，行距与缩进已调好。

### 用法

```bash
pip install python-docx
python tools/md2docx.py 路径/教程一.md 路径/教程二.md   # 输出同目录同名 .docx
```

### 说明与边界

- 面向本仓库这类「文字 + 表格 + 代码」的技术教程，覆盖常用 GFM 子集；
- 不处理图片（本库教程均为纯文字/表格/代码）；如需插图可在此基础上扩展 `add_picture`；
- 转换是**单向**的（md → docx），以 Markdown 为唯一源文件，修改内容请改 `.md` 后重新生成，不要手改 `.docx`。
