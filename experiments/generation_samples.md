# 生成样例对比（Generation Samples）

统一使用 `eval_llm.py` 内置的 8 个中文问题，`temperature=0.7、top_p=0.95`，FP16 解码。
对比三个检查点：**pretrain-only（未对齐）**、**small-SFT**、**medium-SFT**。原始完整输出见各目录 `gen_*.txt`。

---

## 一、消融：Pretrain-only vs SFT（证明指令对齐来自 SFT）

**Q：请用 Python 写一个计算斐波那契数列的函数**

- Pretrain-only（只会续写，无法遵循指令）：
  > 。1, 2, 3, 5, 8, 9, 7, 9, 10, 5, 7, 9, 1, 6, 7, 8, 9, 1, 8, 10, 2, 9, 1, 5, 5, 9 …
- Medium-SFT（学会了「写代码」的指令意图与 markdown 代码块，但 63M 模型逻辑仍有误）：
  > 这是一个使用 Python 编写的计算斐波那契数列的函数：
  > ```python
  > def fibonacci(n):
  >     if n <= 1:
  >         return n * factorial(n-1)
  >     return fibonacci(n-2)
  > ```

**结论**：pretrain 只学到语言分布，SFT 之后才学会「以助手身份、按格式响应指令」。

---

## 二、Small-SFT vs Medium-SFT（数据规模效应）

**Q：解释什么是机器学习**

- Small-SFT：
  > 深度学习（RNN）：是机器学习的一种，它从数据中学习……机器学习是一种人工智能的分支，它通过机器学习来学习数据，包括训练数据、预测模型和目标。
- Medium-SFT（更连贯、定义更准确）：
  > 机器学习是一种人工智能的分支，它通过算法和统计模型，使计算机能够从数据中学习……核心是让计算机通过数据学习来改进自身表现，并根据实际情况做出预测或决策。

**Q：你有什么特长？**

- Small-SFT：
  > 我是一个 AI 助手，无法实时获取实时数据……以下是一些可能的解决方案：1. 数据隐私……（答非所问、重复）
- Medium-SFT：
  > 我是一个基于机器学习的 AI 模型，没有主观体验或情感……我的目标是根据用户的需求和偏好，提供有价值的信息，帮助您更好地理解和解答问题。

**Q：推荐一些中国的美食**

- Small-SFT：笼统罗列「鸡肉、豆腐、坚果」等食材；
- Medium-SFT：能给出**烤鸭、红烧肉、炒饭**等具体菜名（但仍存在重复罗列）。

---

## 三、客观局限（不回避）

在仅使用 ~5% 全量数据、63M 参数的设定下，模型仍存在：
- **事实性错误**（如「天空是蓝色因为蓝色光线与大气形成蓝色和绿色」）；
- **重复 / 循环**（光合作用、美食列表出现词语重复）；
- **代码逻辑错误**（斐波那契误用阶乘、递归式写错）。

这些是训练 token 数与模型容量不足导致的，loss 曲线虽已收敛到 2.2，但距离「可信生成」仍需全量数据与更大模型，
正是本复现后续的迭代方向（全量预训练、扩到 216M、再加 DPO/GRPO 对齐）。
