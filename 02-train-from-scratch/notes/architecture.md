## 1. RMSNorm：为什么可以减掉"减均值"这一步

### 1.1 先看 LayerNorm 在做什么

标准 LayerNorm 对一个向量 `x`（维度 d）做两件事：先**中心化**（减去均值），再**缩放**（除以标准差），最后乘可学习的缩放/平移参数：

```
mean = (1/d) Σ x_i
var  = (1/d) Σ (x_i - mean)²
LN(x)_i = (x_i - mean) / sqrt(var + ε) · γ_i + β_i        # γ缩放、β平移
```

### 1.2 RMSNorm 的化简

RMSNorm（Zhang & Sennrich, 2019，LLaMA 系列采用）观察到：真正起稳定作用的主要是**按均方根缩放**，"减均值"和"β 平移"收益很小，于是直接去掉：

```
RMS(x) = sqrt( (1/d) Σ x_i²  + ε )                        # 均方根，不算 mean
RMSNorm(x)_i = x_i / RMS(x) · g_i                          # 只剩一个可学习缩放 g，没有 β
```

- **为什么有效**：归一化的核心是把激活的**尺度**拉回稳定区间，防止层层叠加后数值爆炸/消失；中心化改变的是"原点位置"，对以注意力为主的结构影响不大。
- **省在哪**：少算一次均值、少一组 β 参数、反向传播更简单，在大模型上亿维度累积下来是实打实的算力节省。
- **本项目对应**：`model.py` 里的 RMSNorm 只保存一个 `weight(g)`、没有 bias；前向就是 `x * torch.rsqrt(mean(x²)+eps) * g`，和公式逐行对应。

> 小知识：`rsqrt` 是"倒数开方"的融合算子，一次算出 `1/√·`，比先开方再相除更快、数值更稳。

## 2. RoPE 旋转位置编码：为什么注意力内积只依赖相对位置

### 2.1 出发点：想把位置信息"旋"进 Q、K

绝对位置编码把位置向量**加**到输入上；RoPE（Su et al., 2021）换了个思路——在算注意力之前，用一个**依赖位置 m 的旋转矩阵 R(m)** 去旋转 Q、K：

```
Q_m' = R(m) Q_m        （位置 m 的查询）
K_n' = R(n) K_n        （位置 n 的键）
注意力分数 = <Q_m', K_n'>
```

目标是让这个内积**只和相对距离 (m−n) 有关**，而不关心 m、n 的绝对大小。

### 2.2 二维最小例子

把向量两两分组，每一组看成二维平面上的一个点。二维旋转矩阵就是高中的旋转：

```
R(θ) = [[ cosθ, -sinθ ],
        [ sinθ,  cosθ ]]
```

令位置 m 对应的角度为 `θ = m·θ₀`（θ₀ 是这一维度对的"基频"）。利用复数表示（把二维向量写成复数、旋转=乘以 e^{iθ}）可以干净地证明：

```
< R(mθ₀)q , R(nθ₀)k >  =  < q , R((m−n)θ₀) k >
```

也就是说：**旋转之后两向量的内积，等价于把相对距离 (m−n) 旋到其中一个向量上**——内积里只剩相对位置，绝对位置被消掉了，这正是想要的性质。

### 2.3 从二维升到高维：多个频率一起转

把 d 维向量拆成 d/2 个二维子空间，每个子空间用**不同的基频**：

```
θ_i = 1 / base^( 2i / d ) ,   i = 0 .. d/2−1 ,   本项目 base = 10000
```

- 低 i（低频）：θ 变化慢，负责刻画**长距离**关系；
- 高 i（高频）：θ 变化快，负责刻画**邻近 token** 的细微相对位置。

多频率叠加让模型同时拥有"近看细、远看得见"的位置分辨率，这也是它**外推性更好**的来源：注意力显式以相对距离为参数，而不是只记住"第 100 个位置"这种和训练长度绑定的绝对向量。

### 2.4 实现上的两个工程细节（对照 model.py）

1. **预计算表**：`precompute` 一次性算出每个位置的 cos/sin 表，训练时按序列长度切片，不重复计算；
2. **交错配对旋转**：把向量后半段与前半段配对、做"x_even·cos − x_odd·sin"这类逐元素运算，等价于二维旋转但完全用向量化操作，GPU 上无需构造真正的大旋转矩阵。

## 3. MHA / GQA / MQA：用 KV Cache 显存公式看清三者差别

### 3.1 区别只在 K、V 头怎么共享

设 Q 头数为 `h_q`，K/V 头数为 `h_kv`，头维度为 `d_h`，层数 L，序列长 T，批大小 b，每个元素占 2 字节（bf16）：

```
单份 KV Cache 元素数 = 2(K和V) · L · h_kv · d_h · T
KV Cache 显存(字节) = b · 2 · L · h_kv · d_h · T · bytes_per_elem
```

- **MHA**：每个 Q 头配独立 K/V，`h_kv = h_q`；
- **MQA**：所有 Q 头**共享一组** K/V，`h_kv = 1`；
- **GQA**：K/V **分组共享**，`1 < h_kv < h_q`，在效果和显存间折中。

注意公式里只有 `h_kv`、没有 `h_q`——**KV Cache 大小正比于 KV 头数，与 Q 头数无关**。这就是为什么省显存靠减 K/V 头。

### 3.2 本项目的消融实测（同骨架，只改注意力类型）

本项目手写模型为 8 Q 头、4 KV 头的 GQA，在同一骨架上对比三者：

| 指标（序列 4096） | MHA(8 KV头) | GQA(4 KV头) | MQA(1 KV头) |
| --- | --- | --- | --- |
| 推理 KV Cache | 100.7 MB | 50.3 MB | 12.6 MB |
| KV 头数之比 | 8 | 4 | 1 |
| 训练峰值显存(bs8,bf16) | 2623 MB | 2490 MB | 2312 MB |
| 训练吞吐 | 60 k tok/s | 64 | 70 |

两个关键结论（也是容易误解的点）：

1. **推理才是 GQA/MQA 的主战场**：KV Cache 严格按 KV 头数 8:4:1 下降，长上下文、高并发时收益巨大；
2. **训练时省得有限**：训练显存的大头是**激活值**（与 Q 头、批量、序列相关），而激活不随 KV 头数线性下降，所以训练侧只省约 12%。谈"GQA 省显存"要分清是训练还是推理。

## 4. SwiGLU：为什么前馈网络换成门控形式

### 4.1 从 GLU 到 SwiGLU

GLU（Gated Linear Unit）用一路"门"去控制另一路信息能否通过：`GLU(x) = (xW) ⊗ σ(xV)`，σ 是 sigmoid 门。SwiGLU（Shazeer, 2020，LLaMA 采用）把门控换成 SiLU（`SiLU(z)=z·σ(z)`）：

```
标准 FFN :  FFN(x) = SiLU(xW1) W2                  # 两个矩阵
SwiGLU   :  FFN(x) = ( SiLU(xW1) ⊗ (xV) ) W2       # 三个矩阵，多一道逐元素门
```

`⊗` 是逐元素相乘。门控支路 `xV` 决定"每个维度放行多少"，比单纯激活函数更灵活，实测在相同计算预算下困惑度更低。

### 4.2 为什么中间层维度常取 (8/3)·d

SwiGLU 比标准 FFN **多了一个矩阵 V**。为了让"参数量/计算量"和原来的两矩阵 FFN 大致持平，需要把隐藏中间维度从 4d 调小：让三个较小矩阵的总参数约等于两个大矩阵，解出来中间维约为 `(2/3)·4d = 8d/3`，再向上取整到并行友好的倍数（如 128 的倍数）。这就是配置里 `intermediate_size ≈ 2.67·hidden_size` 的由来，不是经验拍脑袋。

## 5. Pre-Norm + 残差：为什么深层网络更稳

### 5.1 Post-Norm 为什么难训

原始 Transformer 是 Post-Norm：先做子层（注意力/FFN），**在残差相加之后**再归一化，`x_{l+1} = LN(x_l + Sublayer(x_l))`。问题在于梯度反向回传时要"穿过"一层层归一化，层数一深，梯度尺度容易爆炸或消失，需要很小心的 warmup。

### 5.2 Pre-Norm 的做法与直觉

现代大模型几乎都用 Pre-Norm：**先归一化再进子层**，并在子层外套一条"干净"的残差高速路：

```
x_{l+1} = x_l + Sublayer( LN(x_l) )
```

- 残差支路 `x_l` 是恒等映射，梯度可以沿它**直接无损地传到底层**；
- LN 被放在支路内部，它对主残差路径的梯度干扰更小；
- 代价是输出可能随层累积略微"漂移"，部分模型会在最后再补一个 Final Norm 收尾。

### 5.3 一句话串起来

RMSNorm 负责**每一步把尺度拉稳**，Pre-Norm + 残差负责**给梯度修一条直达底层的高速路**，RoPE 负责**注入相对位置**，GQA 负责**压缩推理 KV Cache**，SwiGLU 负责**更强的逐维门控**——这五个组件共同构成了现代 Decoder-only Block 的标准形态，也正是 `model.py` 里一个 DecoderBlock 的完整组成。
